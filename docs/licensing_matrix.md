# مصفوفة التراخيص لمنصة متعددة العملاء

| الفئة | المكوّنات | الأثر |
|---|---|---|
| متساهل (MIT / Apache-2.0 / PostgreSQL) | hermes-agent، litellm، chatwoot (النواة)، parlant، promptfoo، crawl4ai، camel_tools، coze-loop، pgmq | الاستخدام والتعديل التجاري مسموح مع الإبقاء على الإشعارات |
| حقوق متبادلة شبكية (AGPL) | postiz، خادم Firecrawl المستضاف ذاتيًا | تعديل يُقدَّم عبر الشبكة يُلزم بنشر المصدر؛ مراجعة قانونية قبل الدمج |
| حقوق متبادلة (GPL-3.0) | MaxKB | التوزيع يُلزم بالمصدر؛ غير مستخدم |
| متاح المصدر بقيود | Dify، FastGPT (منع SaaS متعدد العملاء)، n8n (Sustainable Use) | غير صالح كنواة لهيرمس دون ترخيص تجاري |
| غير تجاري | أوزان FLUX.1 [dev]، بيانات MADAR | يحتاج ترخيصًا تجاريًا أو بديلًا |
| يُتحقق | changedetection.io، مدوّنات اللهجة اليمنية، Wapsell | لا استخدام قبل قراءة الترخيص |
| صور مخزون مجانية (Unsplash License، Pexels License، Pixabay Content License) | صور المنشورات والمواقع | الاستخدام التجاري مسموح بلا نسبة وفق نصوصها كما تُلخَّص عادة؛ تُقرأ النصوص الحالية قبل أول استخدام. القيود المعروفة: لا بيع الصورة كما هي، ولا إيحاء بتأييد شخص أو علامة ظاهرين فيها. قاعدتنا أشد: وسم «صورة توضيحية»، وصفحة الصورة مسجلة، ولا تُعرض كمنتج المنشأة نفسها (service/media_policy.py، 28.19) |

قاعدة: لا يدخل مكوّن الحزمة قبل تسجيل ترخيصه هنا ومراجعته.

## توضيح 1.7
الحكم على كل ترخيص مربوط بنمط الاستخدام المقترح لا بمنع عام: رخصة n8n (Sustainable Use License) تقصر الاستخدام على الأغراض الداخلية أو الشخصية أو غير التجارية وفق نصها؛ استخدامها أداةً داخلية للمؤسس مختلف عن تقديمها ضمن خدمة للعملاء، والثاني هو المرفوض هنا.
